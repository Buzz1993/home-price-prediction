# UI Documentation

Version: 1.0

---

# UI Overview

The existing Streamlit application is the reference implementation for the EstateMind Copilot.

Reuse its workflows, backend integrations, and user experience.

The Next.js frontend should modernize the user interface while preserving the existing functionality.

The frontend is responsible only for presenting data returned by the backend.

Do not redesign workflows or move business logic to the frontend.

---

# Design Principles

- Clean
- Modern
- Responsive
- Minimal
- Reusable Components
- Consistent Layout
- Fast Navigation

Business logic must remain in the backend.

---

# UI Philosophy

The UI should feel like a modern AI SaaS application.

Priorities:

- Simple
- Professional
- Responsive
- Easy to navigate
- Minimal distractions

Avoid unnecessary animations or decorative components.

# UI Guidelines

- Follow the existing Streamlit workflows.
- Keep page navigation consistent.
- Use reusable components.
- Keep layouts responsive.
- Support desktop, tablet, and mobile devices.
- Show loading, empty, success, and error states.
- Do not implement backend business logic in the frontend.
- Improve visual design without changing user workflows.
- Preserve the existing chat-first workflow.
- Preserve the evaluation tray workflow.
